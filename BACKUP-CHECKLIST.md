## After backup, before wipe

- [ ] Verify external drive has all Critical + Personal + Code dirs
- [ ] Verify `~/migration-backup.tar.gz` contents (`tar tzf ~/migration-backup.tar.gz`)
- [ ] Regenerate GitHub SSH key + add pubkey to https://github.com/settings/keys
- [ ] Test `ssh -T git@github.com` works with new key
- [ ] Push uncommitted dotfiles work: `cd ~/dotfiles && git push` (commit `5fbcd76` is ahead of origin)
- [ ] Export browser passwords to portable format (optional but safer than profile copy)

## Restore order (post-wipe, on CachyOS)

1. Restore `~/.ssh/` from backup, `chmod 600` private keys
2. `ssh -T git@github.com` to verify key works
3. `git clone --recurse-submodules git@github.com:darkmagic66/dotfiles.git ~/dotfiles`
4. `cd ~/dotfiles && bash install.sh`
5. Restore personal dirs from external drive
6. Import browser passwords (or copy profiles back)

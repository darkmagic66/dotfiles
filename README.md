# dotfiles — keyboard-driven

Mouse optional. Linux runs Hyprland (`SUPER`), macOS runs AeroSpace (`Alt`),
everything else is shared. Full keyboard map, install steps, and package
manifest docs: [`agent.md`](agent.md) (written for agents to execute).

```bash
git clone --recursive https://github.com/darkmagic66/dotfiles.git ~/dotfiles
cd ~/dotfiles
./bootstrap
```
